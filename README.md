# Mk.02 — Game Project: Pirate Simulator

`검은물결: 해적 군주 (Blackwake: Pirate Sovereign)`는 브라우저에서 실행되는 싱글플레이 해적 시뮬레이션 게임입니다. 작은 슬루프와 14명의 선원으로 시작해 상선을 습격하고, 적선에 승선하고, 마을을 약탈하며, 전리품으로 함선과 개인 해적 본거지를 성장시킵니다.

## 실행

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드와 미리보기:

```bash
npm run build
npm run preview
```

정적 빌드 결과는 `build/`에 생성됩니다.

## 조작

| 입력 | 기능 |
|---|---|
| `W` / `S` | 돛 펼치기 / 접기 |
| `A` / `D` | 좌현 / 우현 조타 |
| `Q` / `E` | 좌현 / 우현 포대 선택 |
| `Space` | 선택 포대 발사 |
| `1`–`5` | 일반탄, 사슬탄, 산탄, 소이탄, 관통탄 |
| `F` | 조건 충족 시 승선 작전 |
| `M` | 해도 |
| `I` / `C` / `B` | 함선 / 선원단 / 본거지 |
| `Esc` | 일시정지 및 저장 메뉴 |
| 마우스 휠 | 해상 카메라 확대 / 축소 |

항해 키는 설정 화면에서 변경할 수 있습니다. 화면의 포격·탄약·승선 버튼은 마우스와 터치 입력을 지원하며, 760px 이하 화면에서는 좌우 조타·돛 조절 터치 패드가 표시됩니다.

## 플레이 루프

1. 선장, 해적단, 시작 함선, 깃발, 특성과 난이도를 선택합니다.
2. 개인 해적 은신처에서 보급과 시설 상태를 확인합니다.
3. 해도에서 8개 해역 중 발견된 항로를 선택합니다.
4. 실시간 해상 장면에서 풍향을 읽고 함선을 직접 조종합니다.
5. 탄약과 사격 방향을 선택해 적 선체, 돛, 선원과 장비를 파괴합니다.
6. 약해진 함선에 접근해 승선하고, 나포·전향·약탈·침몰 중 하나를 선택합니다.
7. 연안 정착지를 정찰하고 상륙지·접근 방식·투입 인원·장비를 고른 뒤, 제한 시간과 경보를 관리하며 목표를 약탈합니다.
8. 자유항에서 장물과 금지품을 판매하고 선원과 보급품을 확보합니다.
9. 함선을 수리·개조하고 본거지 시설을 건설합니다.
10. 명성, 현상금, 세력 관계와 본거지 탐지 위험이 증가하며 더 위험한 해역과 방어전이 열립니다.

## 구현된 시스템

- Phaser 3 기반 2.5D 해상 렌더링, 항적, 파도, 안개, 비, 포탄, 파편과 화면 흔들림
- 관성, 가속·감속, 회전 반경, 풍각 효율, 손상·과적·선원 수를 반영한 이동 물리
- 좌·우현 포격, 5종 탄약, 사거리·비행 시간·재장전, 선체·돛·선원·조타·대포·화재·침수 피해
- 전술 선택형 승선 전투와 화물 약탈, 함선 나포, 적 선원 전향
- 제한 시간·경보·지원군 압박이 있는 정착지 상륙 약탈
- 17종 자원, 동적 시장 가격, 금지품 거래, 적재 중량과 화물 한도
- 9개 함선 등급과 선체·돛·조타·대포·화물칸·선원실 개조
- 7개 선원 보직, 7개 장교 직책, 사기·충성·피로·급여·전리품 분배
- 7단계 개인 본거지와 16개 선택형 시설, 인력·식량·치안·사기·위생·방어·탐지 운영
- 해적 자유항의 시장, 암시장, 모집, 선술집, 도박장과 경매장
- 8개 해역, 13개 거점, 8개 세력, 현상금·열기·공포·존경·우호·적대 관계
- 나포선에 부하 선장을 임명하고 진형·순찰·약탈·호송·밀수·정찰·방어 명령을 내리는 독립 함대 작전
- 13종 임무 유형, 세력별 발주처, 실시간 마감, 승선·약탈·밀수·방어전과 연결된 절차적 계약 게시판
- 뇌물·위조 신분·기록 소각·은신으로 현상금을 낮추고, 선물·동맹·전쟁 선포로 세력 관계를 변화시키는 외교
- 현상금과 탐지 위험에 의해 발생하는 준비 → 해상 방어 → 상륙 저지 → 내부 전투 본거지 방어전
- 절차적 일일 생산·인구 성장·시장 주기·사건·시설 건설 시간
- Web Audio API로 합성되는 화면별 절차 음악, 바람·파도 환경음, 대포·충돌·승선·UI 효과음과 개별 음량 설정
- IndexedDB 다중 저장 슬롯, 자동·수동 저장, 버전 필드와 이전 저장 마이그레이션
- 데스크톱/태블릿/모바일 대응 UI, 키보드 포커스, 모션 감소·화면 흔들림·피해 수치·렌더링 품질 설정

## 기술 구조

```text
src/
├── lib/
│   ├── audio/            # Web Audio 합성 음향
│   ├── components/       # 앱 셸, 헤더, 내비게이션, 생성/타이틀 UI
│   ├── domain/           # 게임 규칙과 순수 시뮬레이션 함수
│   ├── game/             # Phaser 해상 장면과 Svelte 브리지
│   ├── persistence/      # IndexedDB 저장소와 마이그레이션
│   ├── screens/          # 본거지, 해도, 전투, 승선, 약탈, 관리 화면
│   └── stores/           # 전역 세션·게임 상태와 자동 저장
└── routes/               # SvelteKit 진입점
```

게임 규칙은 Svelte와 Phaser에서 분리된 순수 TypeScript 함수로 구성됩니다. Phaser는 실시간 해상 표현과 입력을 담당하고, Svelte는 관리 UI와 화면 흐름을 담당합니다. 두 계층은 `SeaSceneBridge`를 통해 함선 상태와 전투 결과만 교환합니다.

### 저장 방식

- 게임 상태: IndexedDB 데이터베이스 `blackwake-pirate-simulator`
- 설정과 키 바인딩: `localStorage`
- 현재 저장 버전: `2` (`1` 저장을 함대·임무·방어 기본값으로 자동 마이그레이션)
- 저장 시점: 새 게임, 출항, 전투/승선/약탈/방어 종료, 건설, 함대 명령, 임무 수락·보상, 수동 저장
- 저장 내용: 선장, 함선, 함대, 선원, 장교, 본거지, 자원, 세계, 시장, 세력, 현상금, 임무, 발견 정보와 플레이 시간

## 검증

```bash
npm run check       # Svelte + TypeScript
npm run lint        # ESLint
npm test            # Vitest 도메인 테스트
npm run test:e2e    # Playwright 데스크톱 + 모바일
npm run validate    # check + lint + unit + build
```

Vitest는 풍향 계산, 함선 이동, 대포 사격과 피해, 승선 조건, 정찰·상륙 계획·약탈 보상, 시설 비용·선행 조건·건설, 함대 작전, 절차적 임무, 외교·현상금, 다단계 본거지 방어, 세계 시간, 저장 마이그레이션을 검증합니다. Playwright는 Chromium 데스크톱과 Pixel 7 모바일 뷰에서 선장 생성, 본거지, 실시간 Phaser 항해, 승선·나포, 상륙 정찰·약탈, 함대 명령, 계약 수락, 세력 화면, 다단계 본거지 방어, 일시정지, IndexedDB 저장·브라우저 재시작 후 복원을 검증합니다.
